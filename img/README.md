# Imágenes

- `logo.png`: logo de Cremita. Se muestra en la barra de arriba y como ícono de la pestaña.
- `productos/`: fotos de los productos. Cada foto se asigna en el campo `imagen` del producto en `js/productos.js`, por ejemplo `"img/productos/dog-chow.jpg"`.

Las fotos se ven mejor horizontales (proporción 4:3) y livianas (menos de 300 KB).
